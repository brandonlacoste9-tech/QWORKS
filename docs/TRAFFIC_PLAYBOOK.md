# Q-Emplois — Traffic playbook (cold start)

**Goal (2 weeks):** Not pageviews. **Real jobs posted + verified taskers who can apply.**

| Metric | Week 1 target | Week 2 target |
|--------|---------------|---------------|
| Real jobs posted | ≥ 8 | ≥ 15 cumulative |
| Verified taskers | ≥ 15 | ≥ 30 |
| Completed jobs | ≥ 5 | ≥ 15 |
| Group / Kijiji posts | ≥ 14 | ≥ 28 |

**Wedge:** Montréal · Rive-Sud · West Island / Pointe-Claire  
**Categories:** déménagement · ménage · montage meubles (only)

**Live links**

| | URL |
|--|-----|
| Home | https://www.quebec-emplois.ca |
| Post a job (client) | https://www.quebec-emplois.ca/book |
| Client help + copy | https://www.quebec-emplois.ca/aide |
| Recruit taskers + copy | https://www.quebec-emplois.ca/recrute |
| Tasker signup | https://www.quebec-emplois.ca/register/tasker |
| Admin (you) | https://www.quebec-emplois.ca/admin |

**Rules**

1. No paid ads until **10+ real jobs** and **10+ verified taskers**.  
2. Same-day ID approve on `/admin` or traffic dies after signup.  
3. FR-first posts; name **one city/quartier** in every title.  
4. Max **3–5 FB groups per day** (avoid spam bans).  
5. Prefer **client posts** Mon/Thu; **taskers** Tue/Fri.

---

## Daily schedule (copy this week)

### Monday — Clients
- [ ] Seed **1 real job** (you or a friend) if board &lt; 5 open  
- [ ] Post in **3** client-style groups (entraide, quartier, parents) → `/aide` or `/book`  
- [ ] 1 Kijiji “Services wanted” → déménagement or ménage  

### Tuesday — Taskers
- [ ] Post in **3** job / side-hustle / student groups → `/recrute`  
- [ ] Clear `/admin` verification queue  
- [ ] DM **5** people: founding credits + link  

### Wednesday — Ops + match
- [ ] Open jobs with **0 applicants** → text verified taskers  
- [ ] Post **1** client + **1** tasker (different groups than Mon/Tue)  
- [ ] Cancel stuck smoke/test jobs  

### Thursday — Clients
- [ ] Same as Monday (new groups)  
- [ ] Ask anyone who completed a job for **1 FR sentence** testimonial  

### Friday — Taskers + proof
- [ ] `/recrute` in 2–3 groups  
- [ ] If you have a completion: 1 short success post (blur names)  

### Saturday — Warm network
- [ ] 10 personal texts (friends/neighbors/work)  
- [ ] Optional: 1 IRL (building board, campus, café)  

### Sunday — Review
- [ ] Fill **tracking table** below  
- [ ] Decide next week: more clients if jobs empty, more taskers if jobs wait  

**Daily ops (15 min, every day):** admin verify → support replies → empty jobs check.

### How to read the numbers

| Signal | Meaning | Action |
|--------|---------|--------|
| Posts ↑ but signups = 0 | Bad link, bad group, or ignored | New groups; stronger first line; post as person not page |
| Taskers ↑, jobs = 0 | Supply only | Stop recruiting 3 days; only seed client jobs |
| Jobs ↑, 0 applies | Unverified taskers or no taskers | Admin queue + more `/recrute` |
| Applies but 0 complete | Ghosting / scheduling | Message both sides; simplify job scope |
| Completions ↑ | Product works | Ask reviews; light boost only then |
